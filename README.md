# Консольная программа для действий с матрицами

Это учебный проект на C++, представляющий собой интерактивный консольный калькулятор для работы с матрицами.

## Возможности
* Сложение и вычитание матриц
* Умножение матриц друг на друга
* Транспонирование матриц
* Умножение матрицы на число (скаляр)
* Интуитивно понятный ввод данных с помощью стрелок на клавиатуре и цветовое выделение активной ячейки

## Как запустить проект
1. Скачайте все файлы из этого репозитория (или нажмите **Code -> Download ZIP**).
2. Откройте файл `nmas.sln` с помощью **Visual Studio** (2019 или 2022).
3. Нажмите `F5` (или зеленую кнопку "Пуск" сверху), чтобы собрать и запустить программу.

## Требования
* Операционная система: Windows
* Среда разработки: Visual Studio (C++)
